## Credit Card manager app

Tech Stack : 1) React Native 2) Expo 3)Typescript

The goal was to recreate a screen (not necessarily the exact same one as the what our app has) that has a similar basic function of app. 

This sample app was built with React Native, Expo, and TypeScript, and for demo purposes it runs in the browser as a web app. The user enters a credit card’s name(open ended name that the user wants to give), current balance, credit limit, and APR, and the app calculates and displays that card’s utilization percentage and estimated monthly interest. It also totals the balance, limit, and monthly interest across all cards and shows a color coded progress bar depending on the limit. Cards can be added and removed, and the app updates everything instantly using React state. For demo purposes, the data is stored only in memory, so it resets on reload.
